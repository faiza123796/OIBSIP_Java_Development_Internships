# OIBSIP Java Task 2 – Number Guessing Game

## Objective
To develop a simple Java-based Number Guessing Game where the user tries to guess a randomly generated number.

## Steps Performed
1. Generated a random number.
2. Accepted guesses from the user.
3. Compared each guess with the generated number.
4. Displayed whether the guess was higher or lower.
5. Limited the number of attempts.
6. Displayed the result after the game ended.

## Tools Used
- Java
- Eclipse IDE
- GitHub

## Outcome
Successfully developed and executed the Number Guessing Game as part of the Oasis Infobyte Java Development Internship.
